# Changelog

All notable changes to Streams Reader are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/):
while the version is `0.x`, a minor bump may break compatibility; patch releases never do. The app, the Worker and
the speech engine share one version; the engine's wire contract has its own number (`CONTRACT_VERSION`, currently 1)
and the HTTP API its own (`x-nolabs-api`, currently 2).

## [Unreleased]

### Added
- Accounts for several users on Supabase: email code sign-in, invite-only sign-up for every provider, linked sign-in
  methods, per-user libraries and progress with row-level security, a per-user share of the daily expressive budget.
- Sign-in emails in 8 languages sent through Brevo from a signature-verified Supabase hook.
- Central brand tokens (`brand/tokens.toml`) driving every colour, radius, size and component, with contrast checks.
- The pixel-grid Streams Reader mark and app icons for Android, macOS, Windows, Linux and the web.
- Static, multilingual landing site (8 languages, right-to-left Arabic) with robots.txt, sitemap, llms.txt and
  security.txt.
- A reusable 3D film studio (`media/`) and the first 41-second promo with music generated by ACE-Step.
- Tauri 2 native apps scaffold: audio engine, bridge, Android media plugin (work in progress).
- Real-browser test harness for the player (`crates/player/harness`).

### Changed
- The Worker verifies Supabase JWTs instead of a single passphrase; HTTP API version 2.
- Product renamed from the working name "nolabs" to **Streams Reader**; the repository is public.

### Fixed
- Player: highlight one segment ahead (MediaSource `timestampOffset` holds the segment start), short skips across
  segment boundaries, skips pressed while a segment loads, highlight lag.

## [0.1.0] - 2026-10-30

First deploy at listen.streams.watch.

### Added
- Speech engine on a ZeroGPU Space: Kokoro-82M on CPU (standard voices), Ming-3.0-tts-0.5B on GPU (expressive),
  WebM/Opus output with silence trimming, boundary pauses and batch loudness, written straight to R2.
- Cloudflare Worker API in Rust: documents, async render queue with content-addressed cache, GPU budget, audio with
  Range support, SSRF-safe article fetcher, cron keep-alive.
- Leptos web app: library, reader with sentence and word highlighting, gapless player with Media Session, voices,
  voice recording, importers for EPUB, HTML, Markdown, text and PDF.
- Node-free deploy tooling (`cargo xtask`).
